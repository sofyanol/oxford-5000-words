# تسليم إلى أداة برمجة أخرى

> **Historical guide:** Use the canonical English handoff system in
> `AGENTS.md`, `docs/HANDOFF.md`, `docs/TASKS.md`, and `docs/DECISIONS.md`
> first. This file is retained for historical context and is not the source of
> current instructions.

هذا المستند موجّه للوكيل أو المطوّر الذي سيستلم المشروع. **اقرأ `START-HERE.md`
أولًا**؛ فهو التعليمات الكاملة القابلة للتنفيذ: كيف تفتح المشروع، وكيف تبنيه،
وكيف تعدّله، وما القواعد الثابتة. بعد ذلك اقرأ هذا الملف للقرارات، ثم
`docs/ARCHITECTURE.md` و`docs/HOW-TO-EDIT.md` حسب الحاجة، و`docs/CHANGELOG.md`
لمعرفة ما تغيّر في كل إصدار. كل شيء داخل هذا المجلد مستقل: لا يحتاج المجلد القديم
ولا أي خدمة خارجية.

## 1. ما هذا المشروع

تطبيق بطاقات مفردات إنجليزي بملف HTML واحد. 4954 كلمة من Oxford 3000/5000، مع
ترجمة الكلمة والجملة إلى لغة الواجهة، وصيغ الكلمة، ونطق IPA مكتوب، وتلوين صرفي،
واختبار خيارات وتكرار متباعد، ومزامنة سريعة برابط أو رمز. لا يوجد نطق صوتي.

## 2. حالة التسليم

- المصدر كامل في `src/` (HTML + CSS + JS).
- البيانات كاملة في `data/` (كلمات، جمل، صيغ، IPA، 11 لغة واجهة، ترجمات).
- البناء يعمل وينتج `dist/oxford5000-flashcards-final.html`.
- الاختبار الذاتي ينجح: `SELFTEST PASS` بلا أخطاء كونسول.
- لا يوجد git repo. إن أردت إصدارًا، أنشئ واحدًا من هنا.

## 3. أوامر التحقق

```bash
python build/build.py
python -m http.server 8765
# افتح http://127.0.0.1:8765/dist/oxford5000-flashcards-final.html#selftest
```

يجب أن يظهر في الكونسول:

```
SELFTEST PASS
```

وإن أردت فتح الملف مباشرة من القرص فهو يعمل أيضًا.

## 4. قرارات مهمة اتُّخذت ولا يُنصح بنقضها بلا سبب

| القرار | السبب |
|---|---|
| البيانات تُحقن وقت البناء لا تُجلب وقت التشغيل | التطبيق يعمل دون إنترنت، وملف واحد قابل للنقل |
| الترجمة تُخزَّن كمصفوفات مفهرسة لا ككائنات نصية | يقلّل الحجم إلى النصف تقريبًا |
| أمثلة الصيغ تُؤخذ من المدونة نفسها بفهرس | يضمن أن الجملة تحتوي الصيغة فعلًا وتجنّب ترجمة آلية جديدة |
| الجموع المنتظمة تُضاف فقط إن وردت في المدونة | لا يمكن تخمين قابلية العدّ بأمان |
| `answerFor` = ملاحظة المستخدم ثم الترجمة المدمجة | يحترم ملاحظة المستخدم ولا يعطّل الاختبار لمن لا يكتب ملاحظات |
| السؤال المجاب يبقى مجمّدًا عند تغيير اللغة | لا تتغير نتيجة سؤال تمت الإجابة عنه بأثر رجعي |
| إزالة النطق الصوتي ونوع الإملاء نهائيًا | قرار المستخدم؛ IPA نص فقط، والإملاء كان يعتمد على الصوت |
| الاختبار خيارات فقط باتجاه «كلمة ← معنى» | قرار المستخدم؛ أبسط وأسرع من الكتابة والبطاقات الذاتية |
| مزامنة بلا خادم عبر رابط `#sync=` ورمز OX6 | لا حساب ولا خدمة سحابية، ويعمل الملف من أي استضافة ثابتة |
| تجميع القوائم حسب المستوى عند الفرز بالصعوبة | طلب المستخدم تصنيفًا واضحًا لكل مستوى |
| رمز تلقرام في مفتاح منفصل | لا يدخل `state` ولا ملف التقدم ولا السجلات |

## 5. عقد الواجهة والنصوص

- لا نص مرئي خارج `data/i18n.json`. أي إضافة تحتاج 11 ترجمة ومفتاحًا متطابقًا.
- العناصر النائبة `{n}` يجب أن تتطابق بين اللغات.
- العربية والأردية RTL. لا تفترض LTR في التخطيطات الجديدة.
- الاتجاه في جملة المثال يبقى `ltr` حتى في الواجهة العربية، لأن النص إنجليزي.
- الرموز المسموحة في النصوص: `✓` و`✕` فقط. لا إيموجي.

## 6. ما تم إنجازه في آخر جلسة

- **v4.2:** مزامنة سريعة برابط كامل أو رابط تحديثات (`OX6`)، واختبار خيارات
  فقط باتجاه واحد، وتجميع القوائم حسب المستوى مع ملخص، ومراجعة الكلمات غير
  المعروفة، وتوسيط الكروت.
- ترجمة تلقائية كاملة للكلمات والجمل إلى 10 لغات، محفوظة مسبقًا.
- إضافة IPA وأجزاء الكلام من مصادر عامة.
- بناء `forms.json` مع الأفعال الشاذة والجموع والصفات، و`sent_list.json`.
- تلوين ثلاثي مع شرح داخل البطاقة، وتحديث التمييز ليعرف الجذع واللاحقة والتغيّر.
- شريط صيغ تفاعلي يعرض مثال الصيغة المختارة، متوسط أفقيًا تحت البطاقة.
- ترجمة الكلمة تحت الكلمة، وترجمة الجملة تحت الجملة، وتكبير جملة المثال.
- مبدّل لغة بأيقونة وشارة كود وسهم.
- دمج الترجمة المدمجة في الاختبار والبحث وقوائم المراجعة.
- تحديث الاختبار الذاتي ليشمل الصيغ والترجمة والتلوين والمزامنة والقوائم.
- تقسيم المصدر إلى HTML/CSS/JS وتوثيق كامل.

## 7. قيود معروفة

- الترجمة الآلية ليست معجمًا؛ بعض تعدد المعاني ناقص. لا تدّعِ دقة معجمية كاملة.
- لا صور للكلمات (مقترح مستقبلي).
- بعض الصيغ بلا مثال، وتظهر باهتة عمدًا.
- الترجمة تشمل 10 لغات؛ الإنجليزية لا تحتاج ملف ترجمة.
- حجم الملف النهائي عدة ميغابايت بسبب تضمين كل الترجمات. هذا مقصود للعمل دون
  إنترنت. إن أردت تصغيرًا، يمكن تحميل ملفات `tr` عند الطلب بدل تضمينها.

## 8. أول ما يمكن تحسينه

راجع قسم «أفكار موثّقة لم تُنفّذ» في `docs/FEATURES.md`. الترتيب المقترح:

1. زر إخفاء الترجمة للاختبار الذاتي (أسهل وأعلى أثر فوري).
2. تمرين ملء الفراغ من نفس مدونة الجمل.
3. هدف يومي وسلسلة أيام مرئية.
4. صور أو رسومات للكلمات الحسية.
5. استبدال صناديق SRS بنموذج FSRS.

- [ ] تجربة عربية + إنجليزية، وكلمة شاذة (write) وكلمة جمع شاذ (child).
- [ ] تبديل اللغة والبطاقة والاختبار مفتوحان.
- [ ] البحث بالكلمة وبالترجمة.
