# Changelog

## Update 1.4.0
- Added Daily Study Habit, Goals & Streak Counter (🔥) with customizable daily targets and celebration confetti.
- Added Audio Playback Speed Selector (`1.0x`, `0.8x`, `0.6x`) and Auto-Pronounce on card navigation.
- Added Interactive Spelling & Writing Quiz Mode with cloze sentence, IPA hints, and instant validation.
- Added Fast-Paced Word Match Challenge (Memory Pairs Game) with Web Audio sound effects and combo scoring.
- Added Visual Learning Analytics with SVG CEFR Pentagon Radar chart and Leitner SRS distribution.
- Added One-Click Export to Anki (TSV format with UTF-8 BOM and standard Anki import headers).
- Added Progressive Web App (PWA) manifest (`manifest.webmanifest`) and offline Service Worker (`sw.js`).
- Fixed Unknown words export runtime exception and enhanced visual undo synchronization.
- Updated 12-language localization dictionary across all newly added features.

## Update 1.3.0
- Added Speed Race Mode (Time Attack) with +2s time bonus per correct answer.
- Added Audio-Only Listening Quiz mode.
- Added Smart Word Explorer with 8 sorting modes and CEFR filters.
- Added Word & Sentence Custom Editor.
- Expanded to 12 fully supported languages with flag switcher.
- Added interactive What's New modal and site guide.

## Update 1.2.0
- Expanded core vocabulary dataset to 5,325 entries (Oxford 3000 & 5000).
- Linked 10,460 native MP3 recordings (5,230 UK + 5,230 US).

## Update 1.1.0

- Added verified word form guide.
- Enhanced popup and modal layering.

## Update 1.0.0
