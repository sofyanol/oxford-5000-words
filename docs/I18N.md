# i18n — كل النصوص المرئية

كل نص يراه المستخدم يجب أن يأتي من `data/i18n.json`. لا تكتب نصًا عربيًا أو إنجليزيًا
مباشرًا في `src/app.js` أو `src/index.html`، إلا داخل تعريفات البيانات (أسماء اللغات
مثلًا موجودة في `_langs` أصلًا).

## كيف يعمل

| الدالة | الاستخدام |
|---|---|
| `t('key')` | نص عادي |
| `t('key', { n: 5 })` | يستبدل `{n}` بالقيمة |
| `tFor('fr', 'key', params)` | نص للغة محددة دون تغيير اللغة الحالية |
| `tHtml('key')` | مثل `t` لكنه يحوّل `\n` إلى `<br>` |
| `applyStaticI18n()` | يطبّق `data-i18n` و`data-i18n-title` و`data-i18n-aria` و`data-i18n-placeholder` على DOM |

`langList()` يقرأ `I18N._langs`، و`langDir(code)` يحدد `rtl` للعربية والأردية والباقي
`ltr`. `applyLang` يغيّر `document.documentElement.lang` و`dir` ثم يعيد رسم كل شيء
مفتوح.

## السمات في HTML

```html
<span data-i18n="card.forms"></span>
<button data-i18n-title="card.copy.title" data-i18n-aria="card.copy.title"></button>
<textarea data-i18n-placeholder="card.note.placeholder"></textarea>
```

## قواعد إلزامية

1. كل اللغات تملك نفس عدد المفاتيح (166 حاليًا) ونفس أسماء العناصر النائبة.
   الاختبار الذاتي يتحقق من ذلك ويفشل عند أي اختلاف.
2. لا تترجم محتوى العنصر النائب نفسه؛ ترجم النص حوله فقط.
3. استخدم `dir="auto"` للنصوص التي قد تكون عربية أو إنجليزية، و`unicode-bidi:
   plaintext` عند الحاجة.
4. الإنجليزية هي لغة المصدر للكلمات والجمل، لذلك لا تحتاج ملف `tr/en.json`.
5. عند إضافة مفتاح، أضفه لكل اللغات الـ11 في نفس الالتزام، ثم أعد البناء.
