# جاهزية النشر والمنصات المجانية

آخر تحديث للأسعار والحدود: 15 نوفمبر 2026. الحدود المجانية تتغيّر، فتحقق من صفحة
الأسعار قبل الاعتماد عليها.

## 1. الحكم السريع

التطبيق **جاهز للنشر** كموقع ثابت (Static Site) بلا خادم وبلا قاعدة بيانات. ملف
واحد بحجم 4.73 MB يحتوي كل البيانات، والاختبار الذاتي ينجح، ولا يحتاج أي عملية
بناء على الخادم. أفضل خيارين عمليين:

1. **Cloudflare Pages** — نقل غير محدود للطلبات الثابتة، وحد 25 MiB للملف
   (الملف 4.73 MB)، وشهادة HTTPS واسم مخصص مجانًا.
2. **GitHub Pages** — أبسط نشر عبر مستودع، وحد موقع 1 GB، ونطاق ترددي 100 GB
   شهريًا كحد لين.

بديل سريع بلا حساب تقني: **Netlify Drop**، لكن الخطة المجانية الجديدة تعمل
بنظام أرصدة (300 رصيد شهريًا ≈ 15 GB نقل)، فمناسب للاستخدام الشخصي لا للجمهور.

## 2. قائمة التحقق قبل النشر

- [x] `python build/build.py` ينجح وينتج `dist/oxford5000-flashcards-final.html`.
- [x] `SELFTEST PASS` بلا أخطاء كونسول عند `#selftest`.
- [x] كل النصوص من `i18n.json` (166 مفتاحًا × 11 لغة).
- [x] لا رمز تلقرام في الملف أو التصدير؛ يُخزَّن في `oxford5000_tg` فقط.
- [x] CSP داخل `<meta>` يسمح بالنصوص والأنماط المضمّنة، وخطوط Google، وواجهة
      تلقرام فقط.
- [x] وصف الصفحة و`theme-color` وOG/Twitter وfavicon موجودة.
- [x] يعمل بلا إنترنت بعد التحميل (الخطوط تسقط إلى خطوط النظام).
- [ ] **قبل النشر:** أعد تسمية الملف إلى `index.html` أو اضبط مسار الجذر.
- [ ] **قبل النشر:** افتح الموقع عبر HTTPS وجرّب: بطاقة، تبديل لغة، اختبار،
      مزامنة برابط بين تبويبين، تنزيل الملف، وزر المشاركة.
- [ ] **قبل النشر:** اختبر على هاتف حقيقي (عرض 360px) وتأكد من عدم قصّ الكروت.
- [ ] **قبل النشر:** راجع الترخيص أدناه إن كان النشر عامًا أو تجاريًا.

## 4. النشر على Cloudflare Pages (الموصى به)

### الطريقة الأسرع: الرفع المباشر

1. أنشئ حساب Cloudflare مجانيًا.
2. Workers & Pages ← Create ← Pages ← Upload assets.
3. أنشئ مجلدًا باسم `oxford5000` وضع فيه:
   - `index.html` (نسخة من `dist/oxford5000-flashcards-final.html`).
   - `_headers` (اختياري، انظر أدناه).
4. اسحب المجلد إلى الصفحة ثم Deploy.
5. افتح الرابط `https://<project>.pages.dev` وجرّب `#selftest`.

### الطريقة الآلية عبر Git

1. ارفع المشروع إلى GitHub.
2. في Cloudflare: Pages ← Connect to Git ← اختر المستودع.
3. إعدادات البناء:
   - Framework preset: `None`.
   - Build command: اتركه فارغًا أو `python build/build.py`.
   - Build output directory: `oxford5000-app/dist`.
4. بعد كل `git push` يُنشر الملف تلقائيًا.

### ملف `_headers` مقترح

```
/*
  X-Content-Type-Options: nosniff
  Referrer-Policy: no-referrer
  Permissions-Policy: geolocation=(), microphone=(), camera=()

/index.html
  Cache-Control: public, max-age=300, must-revalidate
```

لا تضف `Content-Security-Policy` في `_headers` فوق CSP الموجود في `<meta>` إلا
إذا نقلت السياسة كاملة، لأن وجود سياستين يقيّد الصفحة بأشدهما.

## 5. النشر على GitHub Pages

1. أنشئ مستودعًا عامًا جديدًا.
2. ارفع `index.html` في الجذر (أو في `docs/`).
3. Settings ← Pages ← Source: `Deploy from a branch`، الفرع `main` والمجلد
   `/ (root)` أو `/docs`.
4. انتظر دقيقة، ثم افتح `https://<user>.github.io/<repo>/`.
5. لا ترفع `dist/` كاملًا إن لم تحتج الملفات المصدرية؛ يكفي `index.html`.

حد الملف الواحد في GitHub هو 100 MiB، والملف 4.73 MB آمن. الحد الموصى به
للمستودع 1 GB.

## 6. أمور تخص هذا التطبيق

### الحجم والتحميل الأول

- 4.73 MB هو حجم كل الكلمات والترجمات داخل الملف. على اتصال بطيء قد يستغرق
  التحميل ثوانيَ؛ لا يوجد هيكل تحميل تدريجي لأن التطبيق بملف واحد.
- Cloudflare يضغط الملف تلقائيًا (gzip/brotli)، والحجم الفعلي المنقول أقل.
- لا تضف صورًا كبيرة أو خطوطًا مضمّنة قبل قياس الأثر.

### الخطوط

- الخطوط تُطلب من Google Fonts. إن حجبتها CSP أو انقطع الإنترنت، يعمل التطبيق
  بخطوط النظام. لاستقلال كامل: احذف وسم Google Fonts أو استضف الخطوط محليًا
  وحدّث CSP.

### المزامنة والرابط

- رابط المزامنة يعمل بين الأجهزة فقط عندما يُفتح التطبيق عبر `http(s)`.
  من `file://` يظهر تحذير `sync.quick.local` ويعمل الرابط على الجهاز نفسه.
- البيانات محلية لكل أصل (origin). نشر التطبيق على نطاق جديد يعني تخزينًا جديدًا،
  لذا انقل التقدم بالرمز أو ملف التقدم قبل تغيير النطاق.
- رابط التحديثات (`syncDelta`) يفترض أن الجهاز الآخر يملك أساسًا سابقًا. للجهاز
  الجديد استخدم الرابط الكامل.

### الخصوصية

- لا خادم ولا تحليلات ولا تتبّع في الكود الحالي.
- Google Fonts وTelegram (اختياري) يتلقيان طلبات شبكة عند الاستخدام.
- رمز بوت تلقرام يبقى في المتصفح فقط ولا يُصدَّر.

### البحث الاجتماعي وSEO

- `<title>` والوصف ووسوم OG/Twitter ثابتة في HTML، لكن محتوى الصفحة يُبنى
  بJavaScript، لذا تظهر محركات البحث الوصف الثابت فقط.
- لا توجد صورة `og:image` لأنها تحتاج رابطًا مطلقًا. إن أضفت صورة، استخدم رابطًا
  كاملًا على النطاق المنشور.
- هذه ليست مشكلة لتطبيق شخصي، لكنها تحدّ من الظهور في نتائج البحث.

## 7. الترخيص والمحتوى

- قائمة الكلمات نفسها مملوكة لدار Oxford University Press، والاستخدام هنا
  تعليمي شخصي. النشر العام المجاني لا يعني ترخيصًا تجاريًا.
- الترجمات مولّدة آليًا وتحتاج مراجعة بشرية قبل استخدام رسمي.
- لا تستخدم شعار Oxford أو توحي باعتماد رسمي من الدار.
- إن أردت نشرًا تجاريًا، راجع ترخيص قائمة الكلمات أو استبدلها بقائمة مفتوحة.

## 8. تحسينات اختيارية قبل جمهور واسع

1. إضافة `og:image` على النطاق المنشور، وربما صفحة هبوط ثابتة للوصف.
2. استضافة الخطوط محليًا أو حذفها لاستقلال كامل عن الشبكة.
3. إضافة `manifest.webmanifest` وأيقونات للتثبيت على الشاشة الرئيسية.
4. ضغط مسبق للملف (`brotli`) إن كانت المنصة لا تضغط تلقائيًا.
5. إضافة صفحة `privacy.html` قصيرة توضح أن التقدم محلي والخطوط خارجية.
6. مراجعة الترجمة الآلية لعينة من الكلمات قبل الاعتماد التعليمي العام.
